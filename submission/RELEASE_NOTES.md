# Release notes

## Version 1.0.0

Initial public submission of Work From Phone, a skills-only plugin for phone-first Codex work.

It enables autonomous workstation execution, mobile-reachable artifact delivery, compact-safe image batching, verified cloud handoff, remote web previews, concise phone interactions, and continuity across long or compacted sessions. It includes no MCP server, external service, authentication flow, analytics, or user data store.
